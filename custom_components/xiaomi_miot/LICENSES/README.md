`core/mijia_gateway_ca.pem` contains Xiaomi's public Mijia Root and MIoT
Central Gateway CA certificates. These certificates are reproduced from
[Xiaomi Home](https://github.com/XiaoMi/ha_xiaomi_home) for Home Assistant
gateway TLS verification and are covered by
[`Xiaomi-Home-LICENSE.md`](Xiaomi-Home-LICENSE.md). No Xiaomi Home source code
is included in the gateway implementation.
